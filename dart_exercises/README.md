### Scenario Description
This console application models a Tech Store Purchase System. It calculates item subtotals, determines packaging layouts using integer division (`~/`) and modulo (`%`) operators, evaluates order thresholds using comparison operators (`>`), and formats output using string interpolation.

---

### Features & Concepts Demonstrated
- **Data Types:** `String`, `int`, `double`, `bool` declared explicitly.
- **Arithmetic Operators:** Multiplication (`*`), Integer Division (`~/`), Modulo (`%`).
- **Comparison Operators:** Greater than (`>`).
- **Console I/O:** Labelled output formatted via string interpolation (`$variable`).
